## 사용 순서

1. 빈탄 매장 → 재고 관리 → 실재고 실사 → 실사표 다운로드를 선택한다.
2. 실사 업무일과 수량의 **기준시각**을 베트남 시간으로 입력한다. 자정 이후 마감은 전날 업무일로 선택할 수 있다. 예약 양식의 POS 수량은 잠정값이며 기준시각이 지나야 확정할 수 있다.
3. `재고실사`의 노란 입력란에 수량을 기록한다. 빈칸은 미실사, 0은 실제 재고 없음이다. 기본 단위 g/ml/ea 또는 지원되는 kg/L 환산을 사용한다. 박스·봉 포장 규격을 추정하지 않는다.
4. 공통 관찰시각은 `실사정보`의 `counted_at`에 입력한다. 품목별 시간이 다르면 행의 `counted_at`을 입력한다. 제외 품목은 수량을 비우고 `excluded_reason`을 작성한다. 고정된 매장·업무일·기준시각·코드·ID는 변경하지 않는다.
5. 실사 엑셀 업로드 후 POS·실측·차이와 이후 +/−를 확인한다. 임시 저장은 재고를 변경하지 않는다. 전체 품목이 실사 또는 명시적으로 제외돼야 확정할 수 있다. 검토 중 새 거래가 있으면 증감을 새로 확인한다.
6. 실사 이력·차이 리포트에서 날짜를 조회한다. 기준시점 POS/실측/차이와 이후 날짜별 증감·계산 재고를 확인하고 Excel 다운로드 또는 인쇄를 이용한다.

새 기능은 v2 양식을 사용한다. 이전 v1 양식 대신 POS에서 새 양식을 다운로드한다. 초안을 다시 올릴 때는 이력의 같은 날짜 양식 다운로드로 최신 버전을 받는다.

## 데이터 처리

- 현재 재고 = 기준시점 실제 재고 + 이후 입고 − 이후 판매·폐기 등 증감. 예: POS 100, 실제 80, 이후 +30/−20/−5 → 현재 85, 실사 차이 −20.
- 실제 재고 변경을 한 번 캡처하고 기존 입고·판매 문서는 그 변경에 연결한다. 같은 거래를 두 번 더하지 않는다. 일반 결제·Office 연결 계약은 유지한다.
- 업무일, 기준시각, 양식 생성, 업로드, 확정 시각은 구분해 저장한다. 확정 리포트는 원래 비교 값을 보존하며 이후 증감만 새로 조회한다.
- 품목의 거래처 연결을 읽어 공급업체명을 저장한다. 양식 준비 시 등록 단가를 고정하며, 과거 거래 가격을 복원한 것으로 표시하지 않는다. 단가가 없는 품목의 차이 금액은 비교 불가로 남긴다.
- 잘못된 날짜·매장·품목·단위·수식·중복·수량은 반영하지 않는다. 최근 확정 실사와 충돌하는 오래된 실사, 발생시각이 불명확한 이력은 확인 대상으로 차단한다. 완료 파일의 동일 재시도는 조정을 추가하지 않는다.
- 운영 전부터 존재한 판매는 실제 주문·결제 시각이 일치하는 이력만 보완한다. 과거 장부 복원에는 누락 조정 여부 확인이 필요하며, 장부 기준이 없는 신규 품목은 기초재고 등록을 명시해야 한다. 모르는 POS 값을 0으로 만들지 않는다.

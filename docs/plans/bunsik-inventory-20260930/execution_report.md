## 실사 업로드 사용 방법

1. **빈탄 매장 → 재고 → 실재고 실사 → 실사표 다운로드**. 영업·입출고와 마지막 재고 소진 처리를 마친 뒤 실사 직전에 받는다.
2. `재고실사` 시트의 `actual_quantity`에 실측 수량을 입력한다. 빈칸은 미실사, 0은 실제 재고 없음이다. 기본 단위는 g/ml/ea이며 kg→g, L→ml도 지원한다.
3. `설정` 시트 B6 `counted_at`에 실제 실사 시각을 입력한다. 예: `2026-10-01T00:40:00+07:00`. 다운로드 이후 시각이어야 한다. 품목별 시각이 다르면 해당 행에 입력한다.
4. 제외 품목은 수량을 비우고 `excluded_reason`에 이유를 입력한다. 제외 품목의 재고를 0으로 바꾸지 않는다.
5. **실사 엑셀 업로드 → 미리보기 → 임시저장 또는 실사 완료**. 임시저장은 재고 미변경. 123개 모두 실사하거나 명시적으로 제외해야 완료할 수 있다.
6. 초안 저장 후 재업로드할 때는 최신 실사표를 다시 다운로드한다. 다운로드 이후 재고가 변하면 완료가 차단된다. **실사 다시 시작**으로 새 표를 받아 다시 조사한다.

운영 다운로드 파일: [stocktake_20261001_0030.xlsx](/Users/andreahn/Downloads/stocktake_20261001_0030.xlsx).

위 파일은 준비된 빈탄 세션에 연결된다. 실사 전에 재고가 움직였다면 새 표를 다운로드해야 한다. 원본 공급업체별 Excel과 적용 결과 대조표는 업로드 양식이 아니다.

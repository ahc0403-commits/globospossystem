# 안전재고 설정 기능 — 2026-10-02

사용 위치: 재고 → 원재료 관리 → 품목의 **안전재고** 버튼. 기존 원재료 수정 창에서도 설정할 수 있다.

- kg·L·개 단위로 입력하며 구매 포장 크기와 독립적으로 g·ml·ea로 환산한다.
- 빈칸은 미설정(NULL), 0은 설정값 0으로 저장한다.
- 재고 현황 및 원재료 상세에서 설정값과 안전재고 이하 여부를 표시한다.
- 공급처·유통기한 정보가 없는 기존 품목도 안전재고만 설정할 수 있다.
- 안전재고 전용 저장은 현재 재고, 실사 수량, 상품 정보, 공급처 단가를 변경하지 않는다.
- 원재료/공급처와 함께 저장할 때는 기존 상업 조건을 유지하고 한 트랜잭션으로 처리한다.
- 매장 관리 권한을 검사하고 다른 매장/발주 담당자/미인증 요청을 차단한다. 기준 단위가 창을 연 이후 달라지면 저장을 거절한다.

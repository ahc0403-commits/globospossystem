# 리포트 현금이체 QR

스토어매니저(`store_admin`)와 브랜드매니저(`brand_admin`)의 리포트에서
현금 카드 또는 **현금이체 QR 생성** 버튼을 누르면 **조회한 하루의 현금 금액**과
**적용된 조회일**을 자동으로 가져온다. 금액은 수정하거나 수동 입력하지 않는다.
기존 관리자·슈퍼관리자 역할에도 동일한 진입점을 제공한다.

조회일이 2026-10-16이면 화면은 `조회일: 16/10/2026`을 표시하고 QR 적요는
`BC BT C Doanh thu 16/10`(23자)이다. 회사명은 제외하고 분식클럽은 `BC`,
빈탄점은 `BT`로 줄인다. `Doanh thu`의 띄어쓰기와 날짜의 `/`를 유지하고,
25자를 넘으면 `Cash`를 `C`로 줄인다. 긴 매장의 기존 짧은 적요 규칙은 유지한다.
QR에 표시된 적요와 실제 인코딩·복사한 적요가 동일하다.

이전 구현의 오늘 날짜 사용, `ddmm` 적요, 수동 금액 입력 동작은 사용자 정정에
따라 폐기했다. 아직 조회 버튼을 누르지 않은 날짜 선택값도 사용하지 않는다.
여러 날을 조회하면 하루 조회를 안내하고 QR을 생성하지 않는다. 조회 결과가
없거나 로딩·오류 상태일 때 진입을 비활성화한다. 금액이 0 이하이거나 VND 정수로
정확히 표현되지 않으면 QR을 만들지 않는다. 양의 정수는 1동 단위를 유지한다.

계좌는 기존 `get_store_collection_bank(p_store_id)` RPC에서 선택한 매장의
법인 수금 계좌를 가져온다. 기존 접근 권한 검사를 사용하며 임의 계좌를 대신
사용하지 않는다. 브랜드·매장명이나 계좌가 없으면 QR 생성을 막는다.
화면 진입 시 계좌 요청 1회, QR 생성·복사·재생성 시 추가 요청은 없다.
계좌 조회 실패 후 명시적으로 재시도하면 1회 더 요청한다.
실제 송금·입금 완료 기록·일일 마감 저장은 수행하지 않는다.

[VietQR 생성 API 문서](https://www.vietqr.io/danh-sach-api/link-tao-ma-nhanh/api-tao-ma-qr)는
적요 25자를 안내한다. 로컬 EMV/NAPAS 생성기의 날짜 `/` 보존은 이 기능에서만
명시적으로 사용하며 기존 고객 결제 QR 정규화는 유지한다. 성조·긴 매장명은
기존 안정적인 약칭 규칙을 유지하고 날짜를 `dd/mm`으로 보존한다.

수정 검증은 과거 조회일·조회 금액·미적용 날짜 변경·0원·소수·기간 조회·로딩을
포함한다. 390/768/1440 너비, 한국어·베트남어·영어, 글자 크기 100%/200%에서
QR 생성과 화면을 확인하며 실제 생성한 QR 이미지도 별도로 해독한다.
화면 및 해독 증거는 `outputs/cash-deposit-report-fix-20261017/`에 저장한다.
운영 배포 증거는 배포 완료 후 별도 JSON에 기록한다. DB 변경은 없다.

로컬 검증 완료: 관련 Flutter 테스트 126건 통과, 정적 분석 통과.
3개 화면의 QR 이미지에서 1,622,160 VND, `BC BT Cash Doanhthu 16/10`,
수금 계좌 테스트 값과 CRC를 독립 검증했다. 실제 은행 앱 송금은 실행하지 않았다.

## 관리자 매출신고하기의 포토 매출 합계

사용자가 법인별 조회 합계 QR을 선택했다. 포토 입금 카드·QR 버튼을 누르면
선택한 법인의 조회된 포토 매출 합계와 해당 법인 수금 계좌를 자동 사용한다.
적요는 `PO Cash Doanh thu 16/10`이고, 조회일은 다음날 입금 예정일과 별개로
조회한 영업일을 사용한다. 기존 포토 등록 확인 기능도 유지한다.
미등록 지점이 있어 합계가 확정되지 않았거나 계좌가 없거나 금액이 0이면 QR을
만들지 않는다. 조회 요약의 계좌를 재사용하여 추가 RPC·매출 원장 전체 조회 없이
동작한다. 포토 자동 수집·기존 매출 데이터·계산서 상태는 변경하지 않는다.

추가 검증: 포토 QR 23건(법인 전환·계좌·1동 금액·날짜 재조회·오류·18개 반응형
조합) 통과. 생성된 포토 QR 3장에서 108,001 VND와 적요·CRC를 독립 검증했다.

최종 두 화면 관련 회귀 테스트 157건, 정적 분석 통과.

## 적요 띄어쓰기 정정

사용자 지시에 따라 `Doanh thu`를 항상 올바르게 띄어 쓴다. 표시·복사·QR 인코딩이
같은 문구를 사용한다. BC BT는 `BC BT C Doanh thu 16/10`(23자)이다.
이전 릴리스의 `Doanhthu` 표기는 폐기하며, 위의 이전 이미지 검증 기록은 당시 형식이다.

띄어쓰기 정정 검증: 관련 테스트 64건·정적 분석 통과, QR 이미지 3장의 적요와 CRC 해독 일치.

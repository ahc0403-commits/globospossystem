# 전가복 층 전달 복구와 메뉴 순서

## 원인과 변경

- 고객 표시 1F/2F는 기존 테이블에서 내부 2F/3F다. 사용자는 `jgbt_floor_1f`/`jgbt_floor_2f`를 사용한다고 확인했다. 기존 계정 동기화는 코드의 1f/2f를 그대로 저장해서 담당 층이 한 층씩 어긋났다.
- 실제 두 계정의 담당 층을 2F/3F로 바로잡았다. 새 migration은 프로필 변경 후에도 이 매장만 올바른 배정을 유지한다. 테이블 UUID·저장 층과 다른 매장 배정은 유지한다.
- 음료 메뉴는 floor_direct지만 매장 floor_direct_beverages_enabled가 false여서 새 음료가 주방 경로로 접수됐다. 설정을 켰고 migration에서도 운영 기준을 확인한다.
- 꺼진 설정으로 잘못 접수된 미착수 음료 세 줄은 잠금·진행수량 0 검증 후 기존 주방 대기를 취소 표시하고 층 직접 제공 원장으로 보정했다. 가격·세금·메뉴 옵션·수량과 제공 완료 수량은 보존했다. 이 일회성 보정은 설정의 일반적인 기존 주문 보존과 구분되는 사용자 요청 장애 복구다. 감사 등록자는 NULL/Codex maintenance로 남기며 관리자 신원을 꾸미지 않았다.
- 고객 원래 음식은 1208, 제로콜라는 1207로 별도 접수돼 있었다. 사용자가 같은 손님 주문이고 1208로 합치라고 확인했다. 미결제 확인 후 콜라 전체 줄과 KDS 원장을 1208 원래 주문으로 옮겼다. 빈 1207 주문은 취소하고 테이블을 비웠다. 가격·세금·메뉴 옵션과 진행수량을 보존했으며, 고객 qr_get_active_order 응답에서 원 음식·콜라와 이후 추가 음식까지 다섯 줄을 확인했다. 타 테이블 조회 범위를 넓히지 않는다.
- 층 화면 제목과 카드에는 전가복의 고객 표시 층을 사용하고, 내부 조회·실시간 채널·제공 요청에는 저장 층을 유지한다.
- 사용자는 주방의 별도 ‘층 전달’ 완료 후에만 층에서 깜빡여야 한다고 확인했다. 개별 메뉴 클릭은 조리 시작으로 분리한다. 기존 서버는 kitchen_started도 kitchen_done으로 바꾸어 층 준비를 만들었으므로, 전가복만 별도 준비 명령으로 처리한다. 준비 수량만 늘리고 층 준비 원장·서빙 수량은 바꾸지 않는다. 기존 층 전달 일괄 명령이 실제 준비 수량을 중복 증가시키지 않도록 보완한다. 배달·포장은 기존 준비 완료 동작을 유지한다.
- 55K 이벤트 짜장면을 면류 맨 위로 올렸다. 관리자 메뉴 목록에 맨 위로/위로/아래로 버튼을 추가한다. 서버에서 최신 순서를 잠그고 계산하며 카테고리 안의 부모 메뉴만 한 번에 갱신한다. 사진·가격·내부 S/L·면밥 ID·다른 카테고리는 보존한다.
- 순서 변경 요청은 RPC 한 번이며 재조회 없이 캐시에 정렬값만 반영한다. 중복 클릭은 저장 중 막고, 실패 시 목록을 유지한다. 500개 합성 메뉴 이동은 PostgreSQL 약 2.16 ms였다. 운영 네트워크·단말 지연 측정은 아니다.

## 검증과 배포

- Flutter 메뉴 순서 provider/휴대폰/데스크톱 및 층 제목 회귀 테스트.
- 실제 PostgreSQL 이동·권한·타 매장/카테고리·내부 옵션 보존·500개 배치 검사.
- 실제 계정 동기화 트리거 실행 후 배정 유지와 타 매장 음료 설정 보존 검사.
- 기존 전체 Flutter·SQL 및 exact SHA 필수 GitHub CI를 유지한다.
- 운영은 공식 배포 스크립트로 20261021130000 명시적 층 전달, 20261021120000 층 배정, 20261021110000 메뉴 순서 migration을 각각 적용한 뒤 web을 배포한다. 각각 독립적인 추가 변경이며 적용 순서는 의존하지 않는다.
- 실제 격리 PostgreSQL에서 조리 시작 두 번·재시도·층 제공 거부·부분/전체 층 전달·구성 메뉴 준비 수량 보존을 검사했다. Flutter에서는 조리 시작 시 미전달 유지와 층 전달 버튼 완료 후 준비 전환, 한 카드에서 미전달 음식·전달 음식·서빙 음식·음료별 깜빡임을 검사한다.
- 사전 운영 설정/주문 복구와 애플리케이션 릴리스 완료를 구분해 기록한다. 실제 고객 주문·조리·서빙을 검증 목적으로 만들지 않는다.

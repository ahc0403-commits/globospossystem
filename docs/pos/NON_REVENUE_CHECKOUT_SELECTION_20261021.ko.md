# 직원 식사·인플루언서 초대 결제 선택 개선

직원 식사와 인플루언서 초대는 `SERVICE` 방식의 매출 제외 마감이다.
기존 화면은 물티슈 수량 확인 전 모든 결제 수단을 비활성화하고, 두 유형을
일반 ‘서비스·매출 제외’ 선택 후 최종 확인창 안에서만 표시했다.

두 유형의 바로 선택 버튼을 결제 영역에 표시한다. 선택 자체는 물티슈 확인
전에도 가능하고, 물티슈 확인 후에도 선택한 유형을 유지한다. 최종 확인창에는
해당 유형을 미리 선택하며 직원 식사에는 직원명, 모든 유형에는 사유와 관리자
PIN을 요구한다. 최종 마감은 기존 물티슈 확인, 온라인, 권한, 영업 마감 조건을
유지한다. 테이블/주문을 바꾸거나 일반 결제 수단을 선택하면 유형 선택을 지운다.

추가 조회나 항목별 RPC는 도입하지 않는다. 유형 선택은 클라이언트 상태만
변경하며, 실제 마감은 기존 단일 `process_non_revenue_payment` RPC를 사용한다.
유형·승인자 감사, 매출 제외, 재고·원가, 세금계산서 정책과 원자 결제는 그대로다.

운영 읽기 확인에서 전가복의 관리자 PIN이 미설정이었다. 관리자 설정 > 설정 >
결제 > 할인 관리자 PIN에서 실제 관리자가 PIN을 등록해야 한다. PIN이나 해시는
이 문서에 기록하지 않는다. 미설정 오류도 할인과 매출 제외 마감에 공통으로
필요한 설정임을 안내하도록 정정한다.

검증은 실제 결제를 생성하지 않는 Flutter 화면 테스트로 두 유형의 선택,
물티슈 확인 전 호출 0회, 확인 후 유형 유지, 필수 입력 검증, 올바른 유형으로
마감 1회, 오프라인 차단, 작은 화면/낮은 데스크톱 배치를 확인한다.
운영 반영과 관리자 PIN 등록 여부는 별도 배포 증거로 기록한다.
